Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): write the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer.

## Entry

> E01: Bread stuck. I am not angry, just disappointed.

52 characters. A real error code, the most common real toaster failure, and a toaster doing parental guilt instead of a burnt-toast pun.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` where the harness sets it). Python 3.13 standard library only, deterministic, byte-identical on every run.
